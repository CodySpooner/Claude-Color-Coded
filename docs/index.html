    Why it stays on

    A window drawn over an app always lands a frame or two behind it, so ordinary overlays slide off their text as you scroll. This one doesn't draw over the sidebar while it moves. It reads each new frame, paints the colors into that frame, and shows the result as one picture, so text and color can't separate. Clicks still pass through to the app.

    Tested with a real mouseResult
    Scrolling with the wheel15 of 15 scrolls landed exactly, and the highlight's distance from its text never changed in 4,268 measurements
    Expanding and collapsing groupsNo wrong pictures in 1,156 frames
    Stopping in the middle of a scroll12 of 12 ended in the right place
    Moving the window6 ms behind the cursor, compared with 2–3 ms with no helper running

    These come from one PC: Windows 11, dark mode, 100% scaling, a 165 Hz screen. The cost is that an expand or collapse appears about 100 ms after the click, because the picture waits until the new row positions match what's on screen.

    Install

    You need 64-bit Windows and the Claude desktop app. You don't need admin rights. There's no window to open, only an icon in the system tray.

    Use the installer

    Download the latest setup file and run it. It installs for your Windows account only and starts with Windows.

    Download from GitHub

    Not code-signed. The installer has no publisher certificate, so Windows may warn you about it. If you'd rather not override a warning, build it yourself instead. Each release lists the file's SHA256.

    Build it yourself

    It's one C# file, compiled with the compiler that comes with Windows.

    PowerShell
    git clone https://github.com/CodySpooner/Claude-Color-Coded.git
cd Claude-Color-Coded
.\build.cmd
.\ClaudeColorCoded.exe

    To start it when you sign in, type shell:startup into File Explorer's address bar and put a shortcut to ClaudeColorCoded.exe in the folder that opens.

    Then open the Code tab in Claude with the sidebar showing, and right-click a group heading. Select font color and Select color appear at the top of the menu.

    Help

    Update

    With the installer, download the latest setup file and run it. It replaces the earlier version and keeps your colors.

    If you built it, quit it from the tray icon, run git pull and .\build.cmd in its folder, then start it again.

    Uninstall

    With the installer, uninstall it from Windows Settings > Apps. If you built it, quit it from the tray icon, then delete its folder and any shortcut you made.

    Your saved colors are in %LOCALAPPDATA%\ClaudeColorCoded, so delete that folder too if you don't want them. It never changes Claude's own files, so there's nothing to undo in the app.

    The color rows don't appear
    Check that the tray icon is there and that you're right-clicking a group heading, not a session. Then run the check below.
    It stopped working after a Claude update

    It relies on the app's English New session in <name> button label and one of its class names, so an update or another display language can break it. Run this in its folder. It lists the headings it can read, or says what failed:

    PowerShell
    .\ClaudeColorCoded.exe --check | Out-String
    Windows or your antivirus blocks it
    Please don't override a warning you're unsure about. Open an issue instead, so it can be looked at. The program isn't code-signed, and it uses a mouse hook and reads the screen, which security software can question. The whole program is one file, claude-color-coded.cs, if you want to read it.
    Known limits
    • It has only been tested on Windows 11 in dark mode. Sizes assume 100% display scaling, and scrolling was tested on a 165 Hz screen.
    • Screen recordings and screenshots taken during a scroll, or just after a click in the sidebar, don't show the colors.
    • On a rotated screen it uses an older, slower way of reading the screen, so scrolling there may look less smooth.
    • A heading that newly appears can take up to 5 seconds to get its colors.
    • HDR hasn't been tested.
    • Picking a color closes the app's menu by sending it the Esc key. If that menu closes by itself in the same instant, the key reaches the app instead, where it could stop a running session.
    • The color picker is mouse-only, so you can't type a hex code.
    • Colors follow a group's name, so a group whose name changes loses its colors.
    • While the sidebar straddles two screens, the part on the other screen has no colors.
